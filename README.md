# portofolio

**Why Deployment Matters**: Bridging Data to Decision Mengubah analisis dari Jupyter Notebook menjadi aplikasi Streamlit yang ter-deploy adalah langkah krusial dalam siklus hidup data science. Meskipun notebook sangat baik untuk eksperimen teknis, format tersebut sering kali menjadi hambatan bagi non-technical stakeholders (klien atau manajer) karena kompleksitas lingkungan pengembangannya. Dengan men-deploy project ini, saya mengubah kode yang rumit menjadi antarmuka web yang mudah diakses (accessible). Hal ini memungkinkan pengguna untuk langsung melihat nilai bisnis dan insight tanpa perlu menginstal Python atau memahami baris kode, menjembatani kesenjangan antara analisis data mentah dan pengambilan keputusan strategis.

**The Power of Interactivity** Dalam dashboard ini, komponen interaktif seperti sliders, dropdowns, dan input forms bukan sekadar hiasan visual, melainkan inti dari pengalaman pengguna. Interaktivitas mengubah laporan yang statis menjadi alat eksplorasi mandiri (self-service analytics). Fitur ini memberdayakan pengguna untuk melakukan analisis "What-If"—misalnya, melihat bagaimana perubahan parameter tertentu mempengaruhi prediksi model atau memfilter data visualisasi secara real-time. Hal ini meningkatkan keterlibatan pengguna dan memastikan bahwa dashboard tidak hanya menyajikan satu cerita, tetapi mampu menjawab berbagai pertanyaan bisnis yang dinamis.
